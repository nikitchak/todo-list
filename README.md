# Список задач (To-Do List)

[![tests](https://github.com/nikitchak/todo-list/actions/workflows/tests.yml/badge.svg)](https://github.com/nikitchak/todo-list/actions/workflows/tests.yml)

Веб-приложение для ведения списка задач. Тестовое задание.

**Рабочий сайт:** https://nikitchak.github.io/todo-list/

## Функционал по заданию

| Требование | Как реализовано |
|---|---|
| Добавление новых задач | Поле ввода, кнопка «Добавить» или Enter. Пустые задачи и задачи из одних пробелов не добавляются |
| Отметка выполненных задач | Чекбокс, выполненная задача зачёркивается. Отметку можно снять |
| Удаление задач | Кнопка ✕. В течение 5 секунд удаление можно отменить |
| Сохранение после обновления страницы | `localStorage`: задачи, отметки и порядок сохраняются после перезагрузки |

## Дополнительно

- Приоритет задачи (низкий, обычный, высокий) и срок выполнения, просроченные задачи подсвечиваются
- Редактирование текста: двойной клик по задаче или кнопка с карандашом (Enter сохраняет, Esc отменяет)
- Фильтры «Все / Активные / Выполненные» и поиск по тексту
- Изменение порядка перетаскиванием или стрелками с клавиатуры
- Прогресс выполнения и счётчик оставшихся задач
- Очистка всех выполненных задач с возможностью отмены
- Светлая и тёмная тема (по умолчанию как в системе, выбор запоминается)
- Синхронизация между вкладками браузера
- Адаптивная вёрстка, управление с клавиатуры, подписи для экранных дикторов
- Устойчивость к ошибкам: повреждённые данные в хранилище не ломают приложение, текст задач выводится только как текст (защита от XSS)

## Стек

HTML, CSS и JavaScript без фреймворков и сборки. Автотесты используют встроенный в Node.js тест-раннер и запускаются на GitHub Actions при каждом изменении кода.

```
index.html               разметка страницы
style.css                стили, светлая и тёмная темы
app.js                   интерфейс: отрисовка и обработка действий
todo-core.js             логика задач без привязки к странице (покрыта тестами)
tests/todo-core.test.js  автотесты логики
.github/workflows/       автозапуск тестов на GitHub
```

Логика вынесена в `todo-core.js` отдельно от интерфейса: функции не меняют данные напрямую, а возвращают новый список задач. Поэтому их можно проверить автотестами без браузера.

## Как запустить

- **Сайт:** открыть `index.html` в браузере, сервер не нужен.
- **Автотесты:** `node --test` (Node.js 20+, зависимости не нужны).

## Тестирование

### Автотесты

30 тестов логики: добавление и проверка ввода, отметка, удаление и отмена, редактирование, порядок, фильтры и поиск, сроки, склонение слов, сохранение и загрузка (включая повреждённые данные и недоступное хранилище).

### Ручные тест-кейсы

Проверены в Chrome на ширине 1100 px и 360 px.

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| TC-01 | Ввести текст, нажать «Добавить» | Задача появилась вверху списка, поле очистилось | ✅ |
| TC-02 | Ввести текст, нажать Enter | Задача добавлена | ✅ |
| TC-03 | Добавить пустую задачу или задачу из пробелов | Задача не добавлена, показана подсказка «Введите текст задачи» | ✅ |
| TC-04 | Вставить текст длиннее 200 символов | Поле ограничивает ввод 200 символами | ✅ |
| TC-05 | Отметить задачу чекбоксом | Задача зачёркнута, счётчики и прогресс обновились | ✅ |
| TC-06 | Снять отметку | Задача снова активна | ✅ |
| TC-07 | Нажать ✕ у задачи | Задача удалена, появилась плашка «Задача удалена» | ✅ |
| TC-08 | Нажать «Отменить» на плашке | Задача вернулась на прежнее место | ✅ |
| TC-09 | Обновить страницу (F5) | Задачи, отметки и порядок сохранились | ✅ |
| TC-10 | Записать в `localStorage` повреждённые данные и обновить страницу | Страница открывается без ошибок, список пуст | ✅ |
| TC-11 | Изменить текст: Enter, Esc, пустой текст | Enter сохраняет, Esc отменяет, пустой текст не сохраняется | ✅ |
| TC-12 | Переключить фильтры, ввести поисковый запрос | Показываются только подходящие задачи, поиск не зависит от регистра | ✅ |
| TC-13 | Добавить задачу со вчерашним сроком | Срок подсвечен красным: «Просрочено» | ✅ |
| TC-14 | Добавить задачу с текстом `<img src=x onerror=alert(1)>` | Текст отображается как есть, код не выполняется | ✅ |
| TC-15 | Открыть на ширине 360 px | Всё помещается, горизонтальной прокрутки нет | ✅ |
| TC-16 | Включить тёмную тему и обновить страницу | Тёмная тема сохранилась | ✅ |
